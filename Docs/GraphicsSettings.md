# Настройки графики

Esc → «Настройки». Изменения применяются сразу и сохраняются локально в
PlayerPrefs `Goat.Graphics.V1`. Закрытие меню сбрасывает буфер сохранения на диск;
также предусмотрено сохранение при уходе приложения в фон и выходе.
Настройки не передаются другому игроку и не меняют авторские ассеты ландшафта.

| Параметр | Значения |
| --- | --- |
| Обзор от первого лица | 70–120°, по умолчанию 78°; вертикальный FOV |
| Яркость | 50–150%, исходная — 100% |
| Цветокоррекция | Художественный контраст, насыщенность, оттенок и виньетка: вкл./выкл. |
| Общее качество | Шесть существующих уровней Quality Settings проекта |
| Тени | Выкл., низкие, средние, высокие, максимум |
| Текстуры | Полное разрешение, половина, четверть |
| Сглаживание MSAA | Выкл., 2×, 4×, 8× |
| VSync | Выкл./вкл., при включении частоту задаёт монитор |
| Лимит FPS | Без лимита, 30, 60, 90, 120, 144, 165, 240; доступен при выключенном VSync |

Общее качество загружает существующий пресет, обновляя тени, текстуры и MSAA
в меню. Яркость, FOV, цветокоррекция, VSync и выбранный лимит остаются личными
настройками. Число весов костей сохраняется не меньше четырёх, чтобы низкий
пресет не ломал деформацию козлов. LOD и остальные параметры пресетов берутся
из Quality Settings. Отдельная настройка теней меняет их разрешение, включение,
дальность и каскады, не трогая источники света:

| Тени | Дальность | Каскады |
| --- | --- | --- |
| Низкие | 60 м | Без разделения |
| Средние | 120 м | 2 |
| Высокие | 200 м | 2 |
| Максимум | 350 м | 4 |

Это сокращает повторную отрисовку дальних лесов в теневые карты. Геометрия,
дальность видимости окружения и тени рядом с козлами сохраняются; дальние
динамические тени исчезают раньше прежнего предела 750 м.

«Сбросить графику» восстанавливает значения, считанные при запуске до применения
пользовательского профиля. При отсутствии сохранённого профиля используются
текущие настройки качества проекта; яркость 100%, FOV 78°, цветокоррекция включена.

Яркость — финальная гамма-коррекция сцены после существующего CinematicPostProcess,
без изменения света, материалов, HUD и цвета меню. При 100% дополнительного
прохода нет. Если цветокоррекция выключена, настройка яркости продолжает работать.
Шейдер яркости находится в Resources и включается в сборку.

FOV читается камерой независимо от скина и переключения козла на Tab. Он
сглаженно обновляется даже при локальной паузе меню; третье лицо сохраняет
свой прежний обзор. При 120° перспектива у краёв закономерно искажается.

Лимит FPS и VSync окончательно оцениваются в сборке: частотой перерисовки
редактора Unity управляет сам редактор.
