# GOAT — спуск по скале

## Быстрый запуск

В Unity откройте `Assets/GoatDescent/Scenes/BalanceTestScene.unity`, нажмите **Play** и щёлкните по окну **Game**. Сейчас это короткий прототип: стартовый камень и три прыжка вниз вдоль скалы. **R** сразу возвращает козла к началу.

Управление: **WASD** — двигаться, **Space** — короткий прыжок, **F** — ненадолго опереться копытами о скалу, **Ctrl** — тормозить, **R** — повторить. Рывок, двойной и ракетный прыжки, удар вниз, прицельный отскок и замедление времени отключены у игрового козла.

Игровые выступы собраны из готовых моделей камня в `Assets/GoatDescent/Resources/KenneyNature`. Скальная стена собрана из готовых моделей `Cliff_Tall`, `Cliff_Broken`, `Cliff_Wide` и `Cliff_Corner` в `Assets/GoatDescent/Resources/MainModels`. У моделей есть коллайдеры: козёл стоит на самих камнях. Внутри стены остаётся невидимый резервный коллайдер для зацепа на стыках. Светлые камни подходят для приземления, рыжий предупреждает о рыхлом выступе.

Баланс учитывает четыре опоры. На камне козёл может восстановить устойчивость, а у края потеря нескольких опор и резкий поворот вызывают срыв. Перед прыжком козёл коротко приседает. Это игровая интерпретация движений горных козлов.

Длинная сцена `Assets/GoatDescent/Scenes/MovementTestScene.unity` остаётся отдельным экспериментом. Исходный прототип баланса — `Assets/GoatDescent/Scenes/CliffBalancePrototype.unity`.
